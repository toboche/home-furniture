# home-furniture

Projekty mebli na wymiar do mieszkania: model 3D (jeden plik HTML), lista formatek, nawierty i ustalenia.

- `pralnia/`: szafki do pralni (płyta Egger W1200 ST9 18 mm, centrum.meble.pl)
  - `ustalenia.md`: aktualne decyzje i wymiary (źródło prawdy, aktualizowane przy każdej zmianie)
  - `model3d/index.html`: wizualizacja 3D (Three.js)
  - `etap6/`: skrypty, `formatki.csv`, `kalkulator_nawierty.csv`, `arkusz_nawiertow.pdf`, `gen_fasteners.py`

Procedurę odświeżania po zmianie wymiarów opisuje końcówka `ustalenia.md`. Kolejne pomieszczenia (garderoba, szafka z okapem) to kolejne katalogi obok `pralnia/`.
