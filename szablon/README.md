# Szablon pomieszczenia
Jedna przykładowa szafka S1 (boki, tył, dno, półka, wieniec, front F1 z dwoma zawiasami) w pokoju 1200 × 1000 × 2500.
Służy jako punkt wyjścia dla nowego pomieszczenia i jako test wspólnego kodu (sprawdzany w GitHub Actions).
Instrukcja: README w katalogu głównym, sekcja „Nowe pomieszczenie”.
